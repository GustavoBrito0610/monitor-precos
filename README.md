\# 🔔 Monitor de Preços



Receba alerta no Telegram quando o preço de um produto baixar.



\## Funcionalidades



\- 📦 Cadastro de produtos (Amazon, Kabum)

\- 🔔 Alerta no Telegram quando o preço baixar

\- 📊 Histórico de preços com gráfico

\- 👥 Multi-usuário



\## Como usar



1\. Cria conta em https://monitor-precos.streamlit.app

2\. Descobre seu Chat ID do Telegram (`@userinfobot`)

3\. Cadastra produtos com preço alvo

4\. Recebe alerta quando o preço baixar



\## Tecnologias



\- Streamlit

\- SQLite

\- Requests + BeautifulSoup

\- Telegram Bot API
